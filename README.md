# karpathy-wiki

A TiddlyWiki-based LLM knowledge wiki built with [twillm](https://github.com/Jermolene/twillm), inspired by Karpathy's LLM Wiki pattern. The LLM maintains an Obsidian-compatible vault of Markdown files which TiddlyWiki serves live to a browser — edits from the coding agent, manual editing, or the browser itself are all picked up instantly.

## Quick start

```bash
docker compose up -d   # starts twillm on http://localhost:8082
```

Edit `.md` files in `vault/` (with your LLM agent, editor, or the browser). Changes appear live — no reload needed.

## Directory structure

```
CLAUDE.md              ← Agent instructions for this vault (not served as a wiki page)
docker-compose.yml     ← Docker setup (optional, for running twillm from GHCR)
vault/                 ← The wiki vault — flat directory of tiddler files
  index.md             ← Content catalog (optional; TiddlyWiki live views can replace this)
  *.md                 ← Markdown tiddlers — one concept per file, YAML frontmatter + wikilinks
  *.tid                ← TiddlyWiki wikitext tiddlers — computed views, dashboards
twillm-wiki/           ← Generated by the twillm server (see below for git)
skills/                ← Claude skills (llm-wiki-twillm)
```

## Running with Docker

The provided `docker-compose.yml` uses a [twillm image](https://github.com/Jermolene/twillm) from GHCR and serves the vault. It mounts only `vault/` — twillm auto-detects it via its cwd (`./vault`).

```bash
docker compose up -d   # start detached
docker compose down    # stop
```

The vault is served at `http://localhost:8082`.

**Custom directories:** If your wiki lives elsewhere (e.g. `docs/wiki/`), change the compose mount:

```yaml
volumes:
  - ./docs/wiki:/app/vault:Z
```

Twillm auto-detects `./vault`, `./notes`, or `./content` from its cwd — no config needed for these names. For arbitrary paths you'd need to pass a CLI argument instead of relying on auto-detection.

## Git tracking

**Commit:** all `.md` and `.tid` files in `vault/`, `twillm-wiki/` contents (themes, plugins, custom tiddlers), and `CLAUDE.md`.

**Ignore:**
```
node_modules/

twillm-wiki/tiddlers/$__StoryList.tid
vault/.obsidian/workspace*.json
vault/.obsidian/cache/

.claude/
```

## Working with an LLM Agent

The skill at `skills/karpathy-wiki/` provides conventions for Claude Code: atomic tiddlers, YAML frontmatter, wikilinks, tagging taxonomy. Install it via symlink to `~/.claude/skills/` so it's available across all projects.

## Tiddler format

Markdown with YAML frontmatter:

```markdown
---
title: Some Concept
tags: [concept, synthesis]
rating: 6
---

Body in Markdown. Wiki links: [[Other Tiddler]]
```

The YAML frontmatter maps to native TiddlyWiki fields — arrays become bracketed lists, strings as-is, other types (objects, booleans) stored as JSON. Frontmatter `title` wins over filename; keep them in sync.
